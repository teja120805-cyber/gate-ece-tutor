# Analogy

> Identify the relationship in one pair and apply it to complete another (A : B :: C : ?).

## Intuition

Put the relationship in the first pair into a precise sentence ("A is used to do B", "A is a part of B", "A is measured in B"), then find the option that fits the **same** sentence with C. A vague relationship ("they are related") lets wrong options slip through.

## Common relationship types

| Type | Example |
|---|---|
| tool : function | pen : write :: knife : cut |
| worker : workplace | doctor : hospital :: teacher : school |
| unit : quantity | ohm : resistance :: volt : potential difference |
| part : whole | page : book :: leaf : tree |
| group noun | fish : school :: bird : flock |
| synonym / antonym | brave : courageous; hot : cold |
| cause : effect | virus : infection |
| degree | warm : hot :: cool : cold |
| numerical | 2 : 8 :: 3 : 27 (cubes) |

## Strategy

1. Write the bridge sentence for the first pair.
2. Test each option with the same sentence; eliminate.
3. If more than one option fits, make the sentence more specific.
4. Check the **order** — A : B is not the same as B : A.

## Worked examples

**Example 1.** Pen : Write :: Knife : **Cut** (tool : function).

**Example 2.** Ohm : Resistance :: Volt : **Potential difference** (unit : quantity).

**Example 3.** 2 : 8 :: 3 : **27** (the second term is the cube of the first).

**Example 4.** Fish : School :: Bird : **Flock** (animal : group noun).

## Common traps

- Reversing the order of the relationship.
- Picking a word that is merely associated with C rather than one in the same relationship.

## Summary

- Make a precise bridge sentence; apply it in the same direction; refine it if several options fit.
